# 选材范围

工作集只有 `collections.json` 里的 `tradition-hot`。先前的罗翔说刑法、原神前瞻、吐槽新三国、小约翰可汗、黑神话官方、郭律说刑事和罗翔直播课堂都已移出，不再作为本作品的语料。

六维十七类是弹幕的编码，不是视频分类。视频范围收的是能让这些编码发生的热门传统文化片子，再按载体分成五组，方便比较观众接收方式，而不是把某一组视频当成某一维。

## 热门怎么划

每个检索词单独按页面弹幕计数从高到低翻页。某一页第一条已经低于该词阈值，就停止。接口最多 50 页。阈值写在各条 `queries` 里：节目正名可以低到几百，因为当前公开池往往比历史累计小；汉服、书法、京剧、端午、春节这类宽词把线画高，避免娱乐杂片把文化片子淹没。

标题必须包含 `title_contains`。写了 `title_any` 时，还要再中其中一个词。全局排除词加上该条自己的排除词，命中即丢。跟文化词撞车的游戏联动、考试翻译预测、祝福号、采耳、男团饭拍、翻唱和穿越剧都在全局排除词里。「越剧」是「穿越剧」的连续四字，「社火」会撞上「V社火爆」，「年画」会撞上「两年画完」「少年画出」。这些不能只靠标题里出现目标词，要靠排除词拿掉。英文书法课、指甲油色号和游戏战令皮也不收。兰亭序这条不收同名流行歌，标题还得再出现书法、王羲之、曲水、神龙本、冯承素、行书或兰亭序帖之一。清单若是在规则收紧之前拉的，爬弹幕前会再用当前规则滤一遍。同一支视频被多个检索词打中时，只保留查询表里先出现的那一组。

页面上的弹幕计数用来判断热不热。真正拉下来的是播放器当前公开池的全部分段，可以比页面计数少。

## 五组载体

| 组 | 在比什么 |
| --- | --- |
| 文物博物馆 | 国宝、考古、遗址、青铜与官方文博节目 |
| 典籍诗词 | 典籍、诗词、经典文本 |
| 非遗技艺 | 手艺、非遗、传承人 |
| 戏曲书画 | 戏曲、书画、名画与国乐 |
| 节庆民俗 | 节令、礼俗、汉服与国风礼乐演出 |

## 不进仓库的东西

视频标题、BV 号和页面计数可以记在 `danmaku/lists/`。弹幕正文、银标和模型权重不进 git。页面能打开，不等于这些文字可以再分发或拿去公开训练。
