# 类型清单格式

类型归属要人签字。这份说明只写压缩包怎么读，不表示名单已经签过字。

一个类型是一个 zip。每个视频两份文件：

- `{集合名}/{bvid}.meta.json`：`bvid`、`title`、`parts`、`file`。`parts` 里每一项有 `page`、`duration`（秒）。
- `file` 指向的 `{bvid}.jsonl.gz`。每一行一条弹幕，读取 `progress_ms`、`content`、`ctime`（unix 秒）、`page`。

不读取发言者标识。正文留在运行者机器上，不进公开仓库。

```bash
python -m briefing 类型一.zip 类型二.zip --out demo_out
```

写出 `demo_out/index.html` 和 `demo_out/report.json`。`report.json` 里的 `table` 是结构表，`briefing` 只使用这张表里的数。
